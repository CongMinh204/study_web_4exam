## Mảng 6: Exception và Lock Object

### Câu 1. What is the purpose of CX_STATIC_CHECK exception class? (Choose 1 answer)
- A. It is raised when a syntax error occurs during static program checks
- B. It is raised when a runtime error occurs during program execution
- C. It is raised when a logical error is detected in the program
**Đáp án: A**
> Kiểm lại: bản thân exception luôn xảy ra lúc chạy; "static check" nghĩa là trình kiểm tra cú pháp bắt buộc phải xử lý (CATCH) hoặc khai báo (RAISING) exception này. A không chính xác hẳn nhưng là phương án gần nhất trong 3 lựa chọn, giữ A.

### Câu 2. Which exception class is used for dynamic error checks? (Choose 1 answer)
- A. CX_DYNAMIC_CHECK
- B. CX_NO_CHECK
- C. CX_STATIC_CHECK
**Đáp án: A**

### Câu 3. Choose the incorrect information about the exception hierarchy in ABAP. (Choose 1 answer)
- A. Every exception class offers a range of standard methods and attributes are derived from the subclass CX_ROOT.
- B. All exception classes must be derived from one of the classes CX_STATIC_CHECK, CX_DYNAMIC_CHECK or CX_NO_CHECK.
- C. The classes CX_STATIC_CHECK, CX_DYNAMIC_CHECK, CX_NO_CHECK are subclasses of superclass CX_ROOT.
- D. None of the others.
**Đáp án: A**
> Kiểm lại: A là câu sai vì CX_ROOT là lớp cha (superclass), không phải "subclass". B và C đúng. Giữ A.

### Câu 4. What happens when CX_STATIC_CHECK exception class is raised in runtime context? (Choose 1 answer)
- A. The syntax error is displayed as an error message and program execution stops
- B. The syntax error is displayed as a log but program execution continues
- C. The program terminates abruptly
**Đáp án: C**
> Kiểm lại: C đúng về kỹ thuật. Lỗi cú pháp chỉ xuất hiện lúc kiểm tra cú pháp, không phải lúc chạy; khi chạy mà exception không được bắt thì chương trình dừng với runtime error (short dump). Giữ C.

### Câu 30. What is the purpose of an exclusive lock in SAP? (Choose 1 answer)
- A. To prevent other transactions from modifying the locked data
- B. To prevent other transactions from reading the locked data
- C. To allow other transactions to read the locked data concurrently
- D. To allow other transactions to modify the locked data concurrently
**Đáp án: A**

### Câu 31. How can you acquire a lock on a specific data object in SAP? (Choose 1 answer)
- A. Using exclusive-lock mode
- B. Using share-lock mode
- C. Using both share-lock and exclusive-lock simultaneously
- D. You cannot acquire locks on specific data objects in SAP
**Đáp án: A**
> Kiểm lại: câu hỏi mơ hồ, cả shared và exclusive lock đều khóa được đối tượng dữ liệu cụ thể. Giữ A theo bình luận.
